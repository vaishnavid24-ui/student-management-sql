Student Course Management System (MySQL)

## 📌 Description
This project is a basic relational database system built using MySQL to manage student details and course enrollments.

## 🗂️ Tables Used
- Students
- Enrollments

## 🔗 Relationship
One-to-Many relationship:
One student can enroll in multiple courses.

## ⚙️ Features
- Data storage using relational tables
- Use of Primary Key and Foreign Key
- SQL queries for data retrieval and analysis

## 📊 SQL Concepts Used
- SELECT, WHERE, ORDER BY
- JOIN (Inner Join)
- Aggregate Functions (COUNT, SUM, AVG)
- GROUP BY, HAVING
- Subqueries
- Views

## 📈 Sample Insights
- Average marks of students
- Top-performing students
- Course-wise performance

## 🛠️ Tools Used
- MySQL
